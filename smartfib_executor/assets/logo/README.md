# pyFIB logo (v0.54.1)

Chosen by Evan on 2026-10-18 (direction B, "the mill pattern"). The mark is a lamella
mill pattern seen in the FIB view: a trench rectangle above and below a horizontal
lamella, with the marker tick to the left of the lamella. In the wordmark, the "I" is the
same pattern.

## Files

| File | Use |
|---|---|
| `pyfib_mark.svg` | The mark (app icon), vector master, 120 × 120 |
| `pyfib_mark_16.svg`, `pyfib_mark_24.svg` | Pixel-fitted versions for 16 and 24 px |
| `pyfib_mark_<n>.png` | The mark at 16, 24, 32, 48, 64, 128, 256, 512 and 1024 px |
| `pyfib.ico` | Windows icon (16, 24, 32, 48, 64, 128, 256) |
| `pyfib_logo_on_dark.svg/.png` | Mark + wordmark, for dark backgrounds (the GUI's nav bar) |
| `pyfib_logo_on_light.svg/.png` | Mark + wordmark, for light backgrounds (slides, papers) |
| `pyfib_wordmark_on_dark.svg/.png`, `pyfib_wordmark_on_light.svg/.png` | Wordmark alone |

The PNGs have transparent backgrounds. The mark keeps its dark tile on any background.

## Colours

| Role | Hex |
|---|---|
| Accent (trenches, "py" on dark) | `#17c3b2` (the GUI theme's ACCENT) |
| Accent on light backgrounds | `#12776f` |
| Tick | `#f5b841` |
| Tile / tile edge | `#161a22` / `#3a4150` |
| Lamella and "FIB" on dark | `#e7ebf2` (theme TEXT) |
| "FIB" on light | `#1c212b` |

## Type

"py" is JetBrains Mono Medium (500); "F" and "B" are Archivo ExtraBold (800). Both are
SIL Open Font License 1.1 fonts. In the SVGs the letters are converted to outlines, so no
font needs to be installed.

Keep clear space around the logo of at least the width of the tick column. Don't recolour
the mark's parts separately, stretch it, or put the lockup on a busy image.
